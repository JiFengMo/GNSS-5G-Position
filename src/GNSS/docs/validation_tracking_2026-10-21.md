# 北斗 B1C 连续跟踪验收：2026-10-21

已完成捕获种子 → 连续 IQ 相关 → DLL/PLL → 跟踪质量 → 有界重捕获的离线链路。使用与上一阶段相同的真实 IQ；所有开发、数值产物和图像均位于 D 盘主工程。原参考目录保持只读。

## 默认自动模式：7 个通道最终锁定

输入为 `L1_IF20KHz_FS18MHz.bin`，int8 交织 I+jQ、18 Msps、+20 kHz 中频。每颗卫星处理 6000 个完整主码周期，共 42000 个历元。

| PRN | 完整历元 | 有效历元 | 首次有效记录时间 s | 重捕获成功次数 | 有效窗口 C/N0 中位数 dB-Hz | 末尾状态 |
|---|---:|---:|---:|---:|---:|---|
| 23 | 6000 | 5901 | 0.996 | 0 | 51.11 | 锁定 |
| 25 | 6000 | 5801 | 2.000 | 1 | 38.19 | 锁定 |
| 27 | 6000 | 5901 | 1.000 | 0 | 45.81 | 锁定 |
| 28 | 6000 | 5901 | 0.991 | 0 | 49.29 | 锁定 |
| 37 | 6000 | 5901 | 0.992 | 0 | 50.89 | 锁定 |
| 43 | 6000 | 5901 | 0.998 | 0 | 47.80 | 锁定 |
| 46 | 6000 | 5901 | 0.993 | 0 | 43.92 | 锁定 |

开始的约 1 秒用于两个质量窗口的锁定确认，均保留为无效收敛历元。

PRN 25 的初始种子未建立可靠锁定。在记录约 1.010 秒处被判为失锁，自动重捕获成功，随后约 2 秒进入有效状态，并保持到记录结束。其载波初始化从 16575 Hz 改为重新捕获的约 16560.586 Hz；初始失败期间没有输出有效测量。该结果表明“捕获过门限”和“连续跟踪可靠”需要分别判断。

PRN 25 的 `generation` 从 0 变为 1，重新初始化 NCO 相位，并记录一个样本的起点跳转。其余 6 个通道保持单一批次。同一批次内全部相邻历元的样本位置、残余码相位、载波相位和累计圈数连续性检查通过。批次切换没有被伪装成连续载波相位。

## 与重新运行的 MATLAB 对照

数值基线由 CU-SDR `NB_tracking.m` 重新计算，每通道 60 秒。只在工程输出目录的副本中移除进度窗代码，保留参考数值环路。完整 IQ 文件 SHA-256：

`6e16f2e6f37d72d22da1700f0e2139f54ce0f4a946238054ed984da806defe9b`

为了逐历元一对一比较，C 的对照运行使用 `--no-reacquire`。此模式下 6 个通道收敛锁定，PRN 25 保持失锁；C 的全部环路数值仍与参考轨迹一致。参考原有的固定通道 `T` 状态不用于验证锁定质量。

| 对照项目 | 全部 42000 个历元的最大差 |
|---|---:|
| 历元起点样本 | 0 个样本 |
| 载波 NCO 频率 | 1.09e-11 Hz |
| 码率 | 1.16e-10 chip/s |
| 残余码相位（同一时刻） | 1.82e-12 chip |
| 残余载波相位（同一时刻） | 9.09e-13 rad |
| 归一化复相关值差 | 8.7e-13 |

初始化码率的运算顺序与参考统一后，全部通道历元起点完全相同。原始相关器、鉴别器和滤波输出没有依靠降低质量门限来对齐。

对照二进制 SHA-256：`d6a5075b347fb5bfff9883e56d046d785dc06516b17184777712fe256bbafed8`。

本次参考 MATLAB 运行耗时 966.1 秒，C 对照运行耗时 178.9 秒。此处记录的是 18 Msps、7 通道的离线处理；处理 60 秒记录仍需约 179 秒，尚未达到这一配置下的实时吞吐。后续接入 USRP 时需另外优化和实测，不能用离线正确性代替实时验收。

## 专项测试及回归

- 任意输入分块大小得到完全相同的结果；多通道共享文件读取也进行了跨块验证。
- 合成信号包含数据位翻转、真实导频子码翻转、载波/码多普勒、噪声、1 秒信号中断及恢复后的 60 Hz 频率突变。
- 中断后可能出现的约 50 Hz Costas 假锁分支由半历元频差检查识别；失锁批次保持无效，显式重捕获后重新收敛。
- 自动重捕获测试验证最终恢复锁定、频率正确、批次递增、相位重新初始化和间断事件记录。
- 样本间断拒绝拼接；NaN/Inf 输入拒绝；零输入不会被标记为锁定；不足一个完整周期不会输出伪历元。
- ci8/cf32、不同文件读取块、种子/参数校验和短文件状态通过。
- `all-offline` 全工程 15 个 CTest 测试组通过；新增跟踪 CLI 内含 4 项测试。
- GNSS 地址/未定义行为/泄漏检查的 5 个测试组通过；增加非有限输入用例后对应组也已复验。
- `git diff --check` 通过。5G 算法及 UI 源码未改动。
