# B1C 离线基线与捕获验收：2026-10-20

本次重新运行参考代码并完成 C 实现对照，范围为开发阶段 1、2：离线基线、码生成、捕获及精细频率搜索。连续跟踪、电文、定位和 USRP 在线输入不在本次验收范围。

- 原始文件：`CU-SDR-Collection-main/L1_IF20KHz_FS18MHz.bin`，总字节数 2,412,000,000。

- 实际输入窗口 SHA-256：`0299ed8301a26cf80d69c6fecd2fa331b314f65d2283a765bcdab66ae12c5406`。
- MATLAB R2024b (24.2.0.2712019)，参考目录 BDS/B1C，全部 PRN 1–63；积分 10 ms，±5 kHz，粗步长 50 Hz、细步长 25 Hz，门限 10，数据/导频联合处理；未降采样。
- C：Ubuntu/WSL，GCC 13.3.0，FFTW 3.3.10，`gnss-offline` Release 预设。
- 验证二进制 SHA-256：`acea2705ac768da2c0d725c73668e658443457ee7f3891f1b26fd8dedbc0f7fa`。

MATLAB 结果由本工程的 `make_b1c_baseline.m` 调用原参考函数重新计算，没有复用原目录中旧 MAT 文件的捕获结果。原参考目录保持只读。
