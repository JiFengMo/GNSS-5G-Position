# Third-party licensing notes

- `GNSS/GNSS_SDR` contains SoftGNSS-derived MATLAB material. Preserve its
  original `license.txt` and copyright notices when redistributing it.
- `5G` is a local NR-TOA research tree with OAI-style paths and interfaces.
  Review the provenance of any imported OAI source before public release.
- New top-level `include/`, `src/`, `apps/`, `tests/`, `configs/` and `docs/`
  files need an explicit project license before the repository is published.
