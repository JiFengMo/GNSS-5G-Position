## 总体判断

当前工程是以 SSB 接收和时延观测为重点的独立实现。PSS/SSS 与 PBCH 的许多算法沿用或复现 OAI 思路，另加候选重试和诊断处理；它没有整体调用完整 OAI 接收物理层。

PBCH 解码链与 SSB 测距链使用不同的信道估计路径。因此，PBCH CRC 成功只能确认该条解码链通过校验，不能证明测距路径的时延标度、峰值选择和时间关联正确。

当前 PRS 和 5G 模块内部位置解算仍有明确占位实现。之前把 PRS 描述为已有测量链路过于宽泛，应以本文源码检查结果为准。

## 逐项对照

| 算法阶段 | 当前工程 | 本地 OAI | 实际区别 |
|---|---|---|---|
| PSS | 每 4 个采样点做时域相关，多天线相关功率相加，峰均比门限 5，保留最多 4 个候选 | 同样每 4 点时域相关，多天线功率相加，门限同为 5，当前函数输出最强位置 | 数学主干接近；当前用标量浮点/双精度累加，OAI 用定点向量点积；当前增加候选保留和去重 |
| 初始 CFO | PSS 前后半符号相关相位差 | 同样的半符号相关相位差 | 基本相同；当前额外把输出限制在 ±15 kHz，provider 在绝对值达到 14.9 kHz 时拒绝锁定 |
| SSS | PSS 信道共轭补偿、336 个 NID1 与 16 个相位假设；再试 5 个时间偏移 | PSS 信道补偿、NID1/相位搜索，并计算 SSS 残余频偏 | 当前多时间候选，保留多个 PCI 假设；未见直接复用 OAI 的 SSS 残余频偏计算 |
| OFDM 解调 | 每个符号直接计算 240 个子载波的 DFT，内层反复计算正余弦 | `nr_slot_fep` 调用优化 DFT 后端 | 理论变换含义相近，实现成本显著不同；具体速度需要同条件计时 |
| PBCH DMRS 假设 | 搜索 PCI、时间、CFO、SSB index、半帧；先尝试当前假设，失败后保留最多 16 个排序假设 | 对 SSB index/半帧做 DMRS 相关排序后解码 | 当前搜索范围更广，但会重复解调多个时间/CFO 窗口，增加最坏处理量 |
| PBCH 信道估计 | DMRS LS，加 OAI 的 `filt16a_l/m/r` 滤波插值；浮点计算 | DMRS LS、同一组滤波系数、定点向量运算 | 主体思路相同；忽略行尾空白后，两份 `filt16a_32.h` 无差异；不代表数值结果逐位一致 |
| PBCH LLR | 浮点信道共轭补偿，加入噪声/CPE 处理和 LLR 缩放 | 定点信道补偿、缩放、LLR 裁剪到约 ±32 | 输入 Polar 解码器的软信息不等价，弱信号性能需要单独比较 |
| Polar | 先 int16 generic decoder，失败后使用列表长度 8 的 CRC 辅助 SCL | 本地 `nr_rx_pbch` 主路径调用 `polar_decoder_int16`；源码还提供通用列表译码器 | 当前不是简单硬判决或未实现 Polar；有额外回退，但不能直接推断误块率更低 |
| SSB 测距信道 | PSS、SSS、PBCH DMRS 联合 LS；频域线性插值与边缘外推；跨符号平滑与平均 | PBCH 通道用 DMRS 滤波估计，按 OFDM FFT 长度变换到时域 | 当前是独立的测距估计器，没有沿用 PBCH 前端的全部处理 |
| CIR/TOA | 240 点 IDFT、全局最大幅度峰、三点幅度抛物线插值 | PBCH 定时按 OFDM 长度 CIR；PRS 可配置变换长度、最大功率峰、门限及循环索引换算 | 当前存在 CIR 时间网格与接收采样网格混用，见下文 |
| 定时跟踪 | 测试 0、−1、+1、−2、+2 采样偏移，以 DMRS 相关度选整数移位 | CIR 的正负 CP 区间寻峰，IIR 滤波与 PI 调节 | 跟踪反馈量和控制方式不同；当前小数插值点顺序有误 |
| PRS | 提取、信道估计、TOA 文件均为 stub；provider 无条件置锁定 | 有 Gold/QPSK 参考、Comb 映射、信道插值、跨符号平均、CIR、峰值和测量输出 | 当前尚无真实 PRS 测量算法；此 OAI 快照接收插值实际只支持 Comb 2/4，不能因为前面列出 6/12 就认为全部支持 |
| 5G 位置解算 | `nr_pos_build_equations` 清零；`nr_pos_solve_wls` 返回 `valid=0` | 本轮未确认独立通用位置求解接口 | 当前 5G 内部 WLS 尚未实现；`src/fusion/solver` 的 WLS 是另一模块 |

注意：OAI 虽有 PBCH MRC 函数，这个快照的 `nr_rx_pbch` 中对应调用被注释，量化读取第 0 路。因此不能笼统宣称当前 OAI PBCH 主路径已经启用了多天线合并。当前工程也是 PSS 可利用多路，而后续 SSB 解调读取 `rx[0]`。

## 已确认、应优先处理的问题

### 1. CIR bin 不是接收采样点

当前 `nr_ssb_build_cir` 对 240 个等间隔子载波做 240 点 IDFT。若子载波间隔为 Δf，其时域间隔是：

`Δt_CIR = 1 / (240 × Δf)`

当前 `nr_toa_build_meas` 却把 `peak_idx + frac` 直接加到接收采样计数，并按 `1/Fs` 换算时间。仅当 `Fs = 240 × Δf` 时这两个单位才一致。

以 30 kHz、30.72 Msps 为例：

- OFDM FFT 长度是 1024。
- 一个 CIR bin 是 138.8889 ns，即 4.2667 个接收采样点。
- 一个接收采样点是 32.5521 ns。
- 直接相加会把 CIR 残余时延分量缩小到正确值的 240/1024。

用理想单径 `H[k] = exp(−j2πk·d/1024)` 按同一 240 点 IDFT 公式计算：当 `d=12.8` 个接收采样点时，峰值位于 bin 3，真实残余时延为 416.6667 ns，而当前换算给出 97.65625 ns。这是公式数值复现，不是目标硬件测距结果；缩放问题作用于 CIR 残余分量，不意味着整体接收时间戳都缩小同一倍数。

建议统一为 OFDM NFFT 长度、或过采样后的 CIR 网格，显式携带时间步长。若保留 240 点 CIR，至少要先将 CIR bin 换算成接收采样单位，再与硬件计数相加。

证据：`ssb/nr_ssb_chest.c:485`、`ssb/nr_ssb_toa_est.c:61`。OAI 对照：`NR_UE_ESTIMATION/nr_dl_channel_estimation.c:621`、`:477`。

### 2. 负残余时延没有展开循环索引

IDFT 时域是循环表示。上述理想单径改成 `d=−12.8` 时，峰值出现在 bin 237，其有符号 bin 应为 −3。当前将 237 作为正数加入接收时间，会把“FFT 窗口比到达时刻晚一些”解释为很大的正残余时延。

本地 OAI PRS 对超过半个 FFT 长度的延迟做减去 FFT 长度的处理。当前也需要结合允许搜索窗口与参考点做有符号展开，并处理边界上的循环插值。

证据：`ssb/nr_ssb_toa_est.c:13`、`:34`、`:61`。OAI 对照：`NR_UE_ESTIMATION/nr_dl_channel_estimation.c:477`。

### 3. 跟踪的三点插值不满足等间距坐标条件

`nr_ssb_track_timing` 的数组顺序是 `[0,−1,+1,−2,+2]`，却直接取数组前后相邻项代入等间距三点抛物线公式。例如以 +1 为中心，数组邻居是 −1 和 −2，并不是 0 和 +2。

此外，其结果写入 `sync->frac_offset_samp`，当前 TOA 构建没有读取该字段。测距另有 CIR 小数峰估计，二者不是同一项，不能未经定义直接重复相加。应先明确跟踪窗口、整数移动和 CIR 残余的参考关系，再决定该小数状态的用途。

证据：`ssb/nr_ssb_sync.c:1077`、`ssb/nr_ssb_toa_est.c:61`。

### 4. 发射时间尚无跨进程关联

`nr_toa_build_meas` 读取 `nr_toa_get_last_tx_timestamp()`。其数据来自 `nr_anchor_write.c` 的进程内静态变量，只在调用发射函数时更新。

当前锚点和接收机是两个独立可执行程序，接收进程不能读取另一个进程的静态变量；本轮未发现接收机导入 `tx_event.csv` 或其他发射时刻消息的调用路径。按现有独立启动方式，接收侧通常读到 0，使绝对 TOA 的 `valid` 保持 0。

这是尚未贯通的输入关联，不是“共享参考时钟后就能自动解决”的事项。需要按 anchor、PCI、SSB、帧/历元匹配发射事件，统一计数单位与硬件时间基准，并检查陈旧和错配。OAI 的 DL PRS ToA 本身也不能直接等同于绝对传播时间。

证据：`common/nr_anchor_write.c:7`、`:21`、`:51`、`ssb/nr_ssb_toa_est.c:77`。

### 5. 测试通过尚不能证明时延精度

- `test_ssb_sync.c` 有合成 SSB、PBCH 编解码、时间/CFO 扰动和负例检查，具备实际算法覆盖；但同一工程编码器与解码器自洽仍不能替代独立外部向量。
- `test_ssb_toa.c` 只对空 CIR 调用寻峰与插值，没有已知非零延迟、多径或单位换算断言。
- `test_prs_toa.c` 仅引用 provider，没有执行真实 PRS 估计。
- `test_solver.c` 检查空输入函数返回值，没有要求输出有效位置。

因此，上轮 21 项 CTest 通过的结果依然成立，但应解释为这些现有测试通过，不能扩大为 PRS、三维定位和绝对 TOA 已验收。

## 算法局限与待实验确认的风险

- 两边这里的 CIR 寻峰都偏向最强径，不能把 OAI 默认峰值估计器当成已经实现了可靠首径/NLOS 识别。最早到达径弱于反射径时，最强峰与几何传播时延会不同。
- 当前测距路径对各符号频响直接平滑/平均；不同参考的覆盖宽度、边缘外推、残余 CFO 和跨符号相位会影响 CIR。偏差大小需用已知信道实验确认。
- 当前同步阶段的 `snr_db = 10*log10(1+best_metric)` 来自 SSS 归一化相关度，是代理质量量；不是常规信号功率/噪声功率比。当前跟踪未见持续更新该量，不宜拿来标注实测 SNR 或进行物理误差建模。
- 当前 CFO 跟踪将 CP 估计与旧状态按 0.18/0.82 混合，再将 PBCH CPE 除以 SSB 时长反馈。由于该 CPE 的信道也是从同一组导频估计，不能直接把它视为独立的跨时刻频率斜率；需用已知 CFO/相位轨迹验证。
- 当前 OFDM 直接 DFT 内层反复计算三角函数，再叠加 SSS 时间候选、PBCH 时间/CFO 候选和最多 8 路 SCL 回退，最坏处理量较高。优先计时拆解，再选择 FFT、旋转因子预计算、候选网格复用等优化。
- 当前还包含 Type0 CSS/CORESET0、SI-RNTI DCI 1_0 的候选提取与 SC 解码、SIB1 PDSCH grant 推导；这些有算法内容，但不应据此声称已完成完整 SIB1 PDSCH 数据译码或完整 OAI UE 功能。

## 推荐实施顺序

1. 建立独立已知时延基线：正/负整数与小数延迟、不同采样率/SCS、不同 FFT 窗口位置。先修 CIR 单位和循环索引，再判断抛物线插值误差。
2. 修定时跟踪插值坐标；定义并验证窗口移动、累计移位和 CIR 残余的合成关系，检查换窗口后测得的绝对到达时刻是否保持一致。
3. 用相同 IQ 或独立生成的标准向量比较 PSS 命中位置、PCI、CFO、DMRS 相关度、信道频响、LLR、PBCH CRC/SFN/MIB。不能只比较最终有没有锁定。
4. 建立多径测试：直达径更弱、反射径更强、不同信噪比；区分最强径检测与首径测距。
5. 为现有直接 DFT、候选搜索和 Polar 回退分别计时；在保留数值对照的基础上替换为优化实现。
6. 自建锚点场景接通发射事件关联与硬件延迟标定。若转向 PRS，单独实施真正的资源映射、Gold 序列、信道估计和 TOA，并先停用占位路径的无条件锁定行为。
